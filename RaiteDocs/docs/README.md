# Documentación del proyecto

Aplicación web de viajes compartidos (raites) para estudiantes de la Universidad Autónoma de Ciudad Juárez (UACJ).

### Cómo actualizar

1. En Google Docs: **Archivo → Descargar → Markdown (.md)**.
2. Reemplazar el archivo correspondiente en esta carpeta, conservando el mismo nombre.
3. Si cambió algún diagrama, exportarlo como imagen y guardarlo en `diagramas/`.
4. Actualizar la fecha de "Última exportación" en la tabla de arriba.
5. Hacer commit con un mensaje descriptivo, por ejemplo: `docs: actualiza SRS con RF-13`.

## Convenciones

- Los archivos llevan un número al inicio para mantener el orden de lectura (`01-`, `02-`, …).
- Los requerimientos se citan por su identificador (`RF-04`, `RNF-02`) en issues, commits y tarjetas de Jira, para poder rastrear qué trabajo corresponde a cada requerimiento.
- Las ideas nuevas van primero en `notas/`. Una vez que el equipo las aprueba, se agregan al SRS con un nuevo identificador.
